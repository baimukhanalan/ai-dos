# AI Dos · DAMUMED Bridge

Локальное расширение для **авторизованного компьютера регистратуры**. Это не
официальный DAMUMED API и не Codex-плагин. Расширение переносит только уже
подтверждённые записи из очереди AI Dos и сообщает об успехе лишь после того,
как перечитало пациента в выбранном слоте.

## Почему расширение, а не Vercel-бот

- логин DAMUMED и сессия остаются на компьютере клиники;
- пароль не передаётся и не хранится в AI Dos;
- DAMUMED может быть открыт в обычном рабочем Chrome;
- при изменении интерфейса операция останавливается, а не кликает по координатам;
- в очередь не попадают ИИН, жалобы, диагнозы и медицинские документы.

## Что воспроизведено по видео и скриншотам

`Запись на приём → дата/график врача → свободный слот → По поводу →
Государственные → В поликлинике → услуга → Сохранить → подтверждение →
перечитать занятую карточку`.

Один и тот же процесс подходит ВОП, акушеру-гинекологу и
травматологу-ортопеду. Различаются только точный врач, услуга и длительность
слота, которые приходят из записи AI Dos.

## Установка для контрольной проверки

1. Откройте `chrome://extensions`, включите «Режим разработчика».
2. Нажмите «Загрузить распакованное расширение» и выберите эту папку.
3. Авторизуйтесь в `https://reg-ala.dmed.kz` обычным способом и откройте
   «Запись на приём».
4. В расширении оставьте включённой «Безопасную проверку» и нажмите
   «Проверить страницу». В этом режиме очередь не запрашивается.
5. Укажите ID клиники AI Dos и нажмите «Синхронизировать график». Расширение
   последовательно открывает видимые графики, передаёт только врача, кабинет и
   пустые интервалы; ФИО занятых пациентов не отправляются.
6. Для контрольной записи администратор AI Dos задаёт на Vercel
   `MIS_ADAPTER=remote` и `MIS_WORKER_SECRET`, а тот же секрет вводится в
   расширение. Затем безопасный режим выключается и обрабатывается **одна
   тестовая запись**.
7. Автоматический режим включается только после того, как тестовая запись
   появилась в правильном слоте и её проверил сотрудник клиники.

## Что ещё обязательно нужно для запуска

- письменное разрешение клиники на автоматизацию её учётной записи;
- тестовая учётная запись или рабочая сессия без CAPTCHA на каждом действии;
- один тестовый пациент, которого разрешено записывать и отменять;
- DOM-снимок открытой формы (DevTools → Elements → Copy outerHTML) **без ФИО,
  ИИН и телефона пациента**, если первая безопасная проверка сообщит, что
  элементы не распознаны;
- точные значения услуг в выпадающем списке для ВОП, гинеколога и
  травматолога, если они отличаются от названий в AI Dos.

Расширение нельзя включать, если правила DAMUMED или договор клиники запрещают
автоматизацию пользовательского интерфейса. В этом случае остаётся готовый
официальный API-адаптер или ручная задача сотруднику.
